Clean Launcher User Guide

⚠️ Before making any changes, always back up your /Mods folder using the Backup feature in More Tools ➡️ Settings & Utilities. This helps protect your game if anything goes wrong.

✨ Getting Started

When you first open Clean Launcher, you’ll be asked whether you want to set up an Auto Mods folder and allow Clean Launcher to start with your computer.

Auto Mods creates a new folder inside /Mods. Anything you place in this folder — files, folders, or zip archives — will be automatically extracted and sorted. Tray and Save files are moved to their correct locations, while other mod files are extracted and kept neatly organized inside Auto Mods, ready to be tested in game, or moved to a different folder.

If you choose to start Clean Launcher with Windows, Auto Mods will always be active in the background. If you choose not to, you’ll need to open Clean Launcher for the Auto Mods folder to be monitored and sorted.

It’s perfect for download sprees. You can right-click the folder, pin it to Quick Access, and drag your downloads straight into it—no manual extraction required.

You can enable or disable Auto Mods at any time via Settings ➡️ Toggle Auto Mods, or by right-clicking Clean Launcher in the system tray. If the folder is deleted while still enabled, it will be recreated automatically.

🚀 Features

  • 🧹 Clean & Launch Sims 4:
    Cleans cache files and error logs, then launches The Sims 4—all in one click. You can optionally clear only the cache when your /Mods folder has changed, and choose a Mods Profile (see 👤 Manage Mod Profiles) to quickly switch between different CC and gameplay setups.
  • 🔎 Scan Mods Folder:
    Scans your /Mods folder for common issues, including duplicate files, hidden scripts, zipped mods, missing files, and more. You’ll get a clear summary of everything found, with expandable sections for each issue. Use Fix Issues to resolve any problems.
  • 🗂️ Backup Mods, Saves & Tray:
    Zip up your Mods, Saves, or Tray for safe backup, or to transfer to a new computer.
  • 🧩 Organize Mods Folder:
    View your Mods folder as a live folder tree. Drag and drop files to move them, Ctrl+click to select multiple items, and create or delete folders with ease.
  • 👤 Manage Mod Profiles:
    Create different profiles for different playstyles, and switch between them easily. If new CC is detected and you’ll be prompted before switching, and your Default Mods (the folder you started off with) is backed up safely.
  • ⚙️ Settings:
    Update your /Mods folder and game path locations, or reset them to their defaults. Manage Launch settings, enable or disable OneDrive warnings, toggle the Auto Mods folder, and choose whether Clean Launcher starts with Windows. You can also generate a Full Report, which creates a detailed list of your Mods folder to make troubleshooting and support much easier. Help directs you to my website, where you can Contact Me if you need some assistance.
